# StoreShot landing page

Static GitHub Pages site for [storeshot.stackwares.com](https://storeshot.stackwares.com).

## Deploy

Pages is configured to publish from this `docs/` folder on `main`.

- Source: branch `main`, folder `/docs`
- Custom domain: `storeshot.stackwares.com` (see `CNAME`)
- DNS: CNAME `storeshot` → `stackwares.github.io`

## Edit

- `index.html` — the landing page (copy is based on the root README)
- `assets/` — icon, editor screenshot, sample screens

Rebuild nothing — it’s plain HTML/CSS. Push changes to `main` via PR.
