# StoreShot landing page

Static GitHub Pages site for [stackwares.github.io/storeshot-electron](https://stackwares.github.io/storeshot-electron).

## Deploy

Pages publishes from this `docs/` folder on `main`.

- Source: branch `main`, folder `/docs`
- URL: `https://stackwares.github.io/storeshot-electron/`

## Edit

- `index.html` — the landing page (copy is based on the root README)
- `assets/` — icon and editor screenshot

Rebuild nothing — it’s plain HTML/CSS. Push changes to `main` via PR.
