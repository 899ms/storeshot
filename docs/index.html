StoreShot — connected canvas editor

One canvas. Screens that can straddle boundaries and export as exact split crops.

Built for store-ready decks, not slide decks

Everything you need to ship a complete App Store Connect / Play Console screenshot set.

▣

Connected canvas editor

Every screen sits on one horizontal canvas. Phones, captions, and elements can straddle boundaries and export as exact split crops. Isolated mode keeps screens self-contained.

▭

Pixel-exact device frames

iPhone 6.9" and iPad 13" vector frames with true screen aspects — screenshots render edge-to-edge, not stretched.

文

Locales done right

Per-store folder codes (Apple vs Google Play), Fastlane / Standard / Flat export layouts, gap-free screen numbering.

AI

AI translation

Bring your own OpenRouter-compatible key. Translate one screen, one locale, or every locale at once — 5-way concurrent with live status.

⇩

One-click export

Bulk PNG bundles at store dimensions with automatic retries and verified-complete downloads.

{ }

Git-trackable + MCP

Project JSON lives in your workspace — commit it and resume anywhere. Drive the editor from Claude or agents over stdio MCP.

Quick start

Run the web editor on any platform, or build the native macOS shell.

01 — WEB

Any platform

Clone the repo, then bun install and bun dev → open http://localhost:3000.

02 — MACOS

Native app

bun install · bun run build · bun run dist:mac → StoreShot.dmg

03 — SHELL

Electron + dev server

Run bun dev in one terminal and bun run electron:dev in another.

# web editor
git clone https://github.com/stackwares/storeshot-electron.git
cd storeshot-electron
bun install
bun dev          # http://localhost:3000

# macOS package
bun run dist:mac # → StoreShot.dmg
Security

Local-only tool, document-only by design. The /api/* endpoints accept any absolute workspace path with no authentication — do not expose the server beyond localhost, and do not run it for multiple users. Translation API keys stay in your browser and go only to your provider. See SECURITY.md for the full policy.
